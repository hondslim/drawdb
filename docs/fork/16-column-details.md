# #16 Postgres column details and ON DELETE on the edge

## Spec

Model:

- `field.identity`: `"ALWAYS"` or `"BY DEFAULT"` for identity columns. `increment` stays the generic auto-increment flag, and serial columns keep only that.
- `field.generated`: the expression of a `GENERATED ALWAYS AS (...) STORED` column.
- `field.domain`: the domain name, when the column's type is a domain. `field.type` holds the base type.
- `field.isArray` (exists): an array of `field.type`.
- `relationship.deferrable`: `"IMMEDIATE"` (`DEFERRABLE INITIALLY IMMEDIATE`) or `"DEFERRED"` (`DEFERRABLE INITIALLY DEFERRED`). Missing means not deferrable. #8 already treats a deferrable FK as soft.

Sources:

- Share payload (#9), new optional lists, applied on every share import:
  - `postgres.columns: [{table, column, identity, generated, domain}]`.
  - `postgres.foreignKeys: [{table, columns: [...], name, deferrable, initiallyDeferred}]`. Matched to a relationship by FK table and columns, then by name.
- DBML: `text[]` becomes `TEXT` with `isArray`, and exports back as `text[]`.
- Postgres SQL: `GENERATED BY DEFAULT AS IDENTITY` and array types. node-sql-parser 5 cannot parse `GENERATED ALWAYS`, generated columns or `DEFERRABLE`, so those come only from share metadata.

Canvas:

- The field type shows `[]` for arrays, and the domain name in italics (tooltip: "domain over BASE").
- Marker icons before the type: `#` for identity (tooltip `GENERATED ALWAYS AS IDENTITY`), `ƒ` for generated (tooltip with the expression).
- Relationship edges show a small label under the name for `ON DELETE CASCADE`, `SET NULL` and `SET DEFAULT`, and for deferrable FKs, for example "CASCADE · DEFERRED". It shows even when relationship names are hidden, so a cascading FK is recognisable without opening it.

Panels:

- The field summary popover lists identity, generated and domain.
- The relationship panel has a Deferrable select: Not deferrable, Initially immediate, Initially deferred.

Export (Postgres SQL):

- `GENERATED {ALWAYS|BY DEFAULT} AS IDENTITY` from `identity`, otherwise `increment` as today.
- `GENERATED ALWAYS AS (expr) STORED`, with no `DEFAULT`.
- `DEFERRABLE INITIALLY {IMMEDIATE|DEFERRED}` on FKs.
- Domains export the base type, because the domain itself is not in the diagram.
